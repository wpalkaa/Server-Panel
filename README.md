# Server Panel

Panel do zarządzania plikami serwera, zarządzania użytkownikami oraz monitorowania zużycia zasobów.

---

##  Jak uruchomić

### 1. Sklonuj repozytorium
```bash
git clone https://github.com/wpalkaa/Server-Panel
```

### 2. Uruchom
```bash
docker compose up -d
```
